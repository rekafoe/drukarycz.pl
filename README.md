# merch.by

Отдельный сайт сувенирки: футболки и кружки со своим макетом. Редактор на сайте, CRM позже забирает дизайн и заказ.

## Как открыть

```bash
npm install
npm run dev -- --hostname 0.0.0.0 --port 43131
```

Сайт: http://127.0.0.1:43131

Путь: две двери → лавка выбранной вещи → редактор → корзина. В редакторе холст Fabric и 3D футболки и кружки. В CRM заказ пока не уходит. Отделка на лавке — только вид, без ширины рулона.
