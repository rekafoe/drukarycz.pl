# merch.by

Отдельный сайт сувенирки: футболки и кружки со своим макетом. Редактор на сайте, CRM позже забирает дизайн и заказ.

## Как открыть

```bash
npm install
npm run dev -- --hostname 0.0.0.0 --port 43131
```

Сайт: http://127.0.0.1:43131

Интерфейс по-польски, цены-заглушки в zł. Путь: две двери → лавка выбранной вещи → редактор → корзина. Цвет с лавки красит ткань 3D, принт лежит поверх. В редакторе холст Fabric и 3D футболки и кружки. На листе кнопки действий нарисованы своими иконками в коде страницы, без шрифта иконок и без запроса к чужому серверу. Перед корзиной лист говорит, если фото реже 300 dpi, объект вылез за край или текст меньше 5 мм. Белый цвет надписи остаётся на модели. PNG зоны на 300 dpi пишется в `data/prints` на сервере merch, когда человек идёт из редактора в корзину. Модель GLB подгружается после первого кадра. Пока файл едет, в окне пустая студия, без запасной фигуры. Подпись по-польски всплывает при наведении. Названия сторон — Przód, Tył, Obwód — остаются словами. Двери, лавка, холст и корзина лежат на сервере merch: обновление страницы их не стирает. Войти можно по польскому телефону и тестовому коду, он виден в окне входа. Заказ и цена в CRM не уходят. Отделка на лавке — только вид, без ширины рулона.

Страницы regulamin, prywatność, cookies, odstąpienie, reklamacje, dostawa и kontakt лежат в `/prawne`. Корзина просит e-mail, адрес и две отдельные галочки, оплату не берёт. Реквизиты фирмы в `lib/seller.ts` пустые, пока организация их не впишет. Что осталось до продажи — в `docs/plan-prawny.md`.
