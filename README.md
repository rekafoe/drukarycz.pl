# drukarycz.pl

Отдельный сайт сувенирки: футболки и кружки со своим макетом. Редактор на сайте, CRM позже забирает дизайн и заказ.

## Как открыть

```bash
npm install
npm run dev -- --hostname 0.0.0.0 --port 43131
```

Сайт: http://127.0.0.1:43131

Интерфейс по-польски, цены-заглушки в zł. Путь: две двери → лавка выбранной вещи → редактор → корзина. Цвет с лавки красит ткань 3D, принт лежит поверх. В редакторе холст Fabric и 3D футболки и кружки. На листе кнопки действий нарисованы своими иконками в коде страницы, без шрифта иконок и без запроса к чужому серверу. Перед корзиной лист говорит, если фото реже 300 dpi, объект вылез за край или текст меньше 5 мм. Белый цвет надписи остаётся на модели. PNG зоны на 300 dpi пишется в `data/prints` на сервере drukarycz.pl, когда человек идёт из редактора в корзину. Редактор открывается целиком, когда лист и модель уже собраны. До этого на экране только «Otwieramy edytor…». Файл футболки сжат с 6,5 МБ до 300 КБ, а модели и код редактора начинают грузиться уже на дверях. Подпись по-польски всплывает при наведении. Названия сторон — Przód, Tył, Obwód — остаются словами. Двери, лавка, холст и корзина лежат на сервере drukarycz.pl: обновление страницы их не стирает. Войти можно по польскому телефону и тестовому коду, он виден в окне входа. Заказ и цена в CRM не уходят. Отделка на лавке — только вид, без ширины рулона.

Три варианта визуала дверей и лавки на согласование: `/?v=a` — плакат, `/?v=b` — сетка, `/?v=c` — керамика. Без параметра сайт выглядит как раньше. Переключатель вариантов висит в углу экрана. Код вариантов лежит в `components/variants`, редактор и корзина у всех общие. Шрифты (Unbounded, Manrope, Fraunces, IBM Plex Mono, лицензии OFL рядом) лежат в `public/fonts`, снимки вещей — в `public/products`. Снимки сняты с тех же 3D-моделей, что в редакторе; надписи на них примерные.

Страницы regulamin, prywatność, cookies, odstąpienie, reklamacje, dostawa и kontakt лежат в `/prawne`. Корзина просит e-mail, адрес и две отдельные галочки, оплату не берёт. Реквизиты фирмы в `lib/seller.ts` пустые, пока организация их не впишет. Что осталось до продажи — в `docs/plan-prawny.md`.
